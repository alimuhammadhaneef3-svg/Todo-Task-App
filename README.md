# 📝 Todo Task App

A simple and clean **Todo List App** built with HTML, CSS, and JavaScript.

I built this project while learning JavaScript and working on the fundamentals of **DOM manipulation, events, and dynamic HTML elements**. The goal was to keep the app simple while practicing the concepts that are used in real-world JavaScript applications.

## ✨ Features

* ➕ Add new tasks
* ⌨️ Add tasks by pressing **Enter**
* ✅ Mark tasks as completed
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* 🚫 Prevent empty tasks from being added
* 📱 Simple and responsive interface

## 🛠️ Built With

* **HTML5** — Page structure
* **CSS3** — Styling and layout
* **JavaScript** — Functionality and DOM manipulation

## 🚀 How It Works

Type a task into the input field and click **Add**, or simply press **Enter**.

Once a task is added, you can:

**Click the task** → Mark it as completed
**Edit** → Change the task
**Delete** → Remove the task
